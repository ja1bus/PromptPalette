## Libraries / ライブラリ

PromptPalette does not include or load any third-party library. It uses only the APIs provided by Google Chrome (Manifest V3). The tests use only the built-in modules of Node.js (`node:test`, `node:assert` and others); there are no npm packages.

PromptPalette は第三者のライブラリを含まず、読み込みもしません。Google Chrome（Manifest V3）が提供する API だけを使います。テストは Node.js の組み込みモジュール（`node:test`・`node:assert` など）だけを使い、npm パッケージはありません。

The icons in `icons/` were drawn by ja1bus.

`icons/` のアイコンは ja1bus が作成したものです。

## External services / 外部サービス

PromptPalette operates the web pages of ChatGPT (https://chatgpt.com/, a service of OpenAI) and Gemini (https://gemini.google.com/, a service of Google) that the user has opened in Chrome. It does not use their APIs. The images and prompts you send are handled under the terms and policies of each service. If you turn on sharing between PCs, presets are stored in Chrome sync of your Google account.

PromptPalette は、利用者が Chrome で開いた ChatGPT（https://chatgpt.com/ 、OpenAI のサービス）と Gemini（https://gemini.google.com/ 、Google のサービス）の Web ページを操作します。これらの API は使いません。送信した画像とプロンプトは、各サービスの規約とポリシーに従って扱われます。PC 間の共有を有効にすると、プリセットは利用者の Google アカウントの Chrome 同期に保存されます。

PromptPalette is not affiliated with OpenAI or Google.

PromptPalette は OpenAI・Google とは関係のない個人の開発によるものです。
